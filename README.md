## Операции Git, выполненные в лабораторной работе № 1

- настройка Git (`user.name`, `user.email`, `init.defaultBranch`);
- создание локального репозитория (`git init`);
- фиксация изменений (`git add`, `git commit`);
- создание ветви и работа в ней (`git checkout -b`);
- подключение удалённого репозитория (`git remote add origin`);
- отправка и получение изменений (`git push`, `git pull`);
- слияние ветвей (`git merge`, режим Fast-forward).
